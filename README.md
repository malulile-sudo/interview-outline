# interview-outline · AI 创业者访谈 Skill

> 得到马想风格的 AI 创业者 / 企业 AI 转型老板访谈大纲生成器

这不是一个只会罗列“请您谈谈”的采访模板。它会先研究受访者、行业、竞品和消费者，再把事实、采访者判断与待确认信息分开，生成一份可直接录制、能继续追问、也能自然产出传播切片的访谈大纲。

## 它能做什么

1. 检索并验证受访者过去的公开输出，保留原始链接。
2. 对比行业、竞品、替代方案和反方材料，避免做成嘉宾宣传稿。
3. 按固定九大模块生成主问，并为重点问题配置事实追问、反例追问和分支追问。
4. 从老板采购决策出发，追问采用率、客户结果、失败样本、劝退对象和供应商选择标准。
5. 模仿“得到马想”的采访思路：具体老板 + 具体生意 + 具体 AI 动作 + 具体结果 + 马想判断。
6. 规划主视频、冲突切片、金句切片、方法切片和评论区互动。

## 使用

在对话里直接说：

> 帮我准备一份采访 XXX 的大纲。他是 YYY 公司创始人，现在做 ZZZ。我下周二录 60 分钟，这是他过去的分享链接……

或者手动调起：

> /interview-outline 受访者：XXX | 公司：YYY | 赛道：ZZZ | 链接：…… | 时长：60 分钟

如果采访者与嘉宾有课程、采购、投资或渠道合作，也请一并说明，Skill 会把利益披露和背书边界设计进开场与追问。

## 输出结构

```text
【人物基础信息】
- 一句话人设
- 最大冲突点
- 最反差点

【九大模块问题清单】
1. 开场·人设建立
2. 业务·新旧之战
3. 行业·趋势 / 市场 / 竞品
4. 组织·人与 AI
5. 个人·状态与代价 / 使命愿景
6. 建议·AI 落地
7. 嘉宾共情提问
8. 用户关心的四个核心信息
9. 国内外大佬观点对照

【传播切片计划】
- 主视频标题
- 冲突 / 金句 / 方法切片
- 评论区互动话题
```

每个问题会附提问依据和追问，关键问题标记为 `★必问`，引用内容保留原链接。

## 这次升级了什么

- 新增证据账本：区分确认事实、采访者推断和待确认信息。
- 新增反方拷问：主动寻找失败案例、质疑、监管风险和利益冲突。
- 新增老板采购视角：比较自学、培训、工具、代运营和不做等选择。
- 新增对话树：嘉宾回答“是”或“不是”都能继续追，不机械念题。
- 新增合作披露与分层背书：能背书什么、不能承诺什么说清楚。
- 新增“得到马想”传播方法：反共识开头、具体案例、数字证据和可执行动作。

## 适用场景

- 视频号 / 抖音长访谈与短视频切片
- 播客、公众号长访谈、行业媒体专访
- 创业者闭门会、企业 AI 案例探访
- 产品体验、供应商选择与商业合作访谈

## 使用边界

- 近期行业信息、人物观点、价格与产品能力必须现查。
- 企业自报数据不能直接当成行业事实，要追问样本、口径和归因。
- 搜索不到的内容标注“待核实”，不编造原话、数字或客户案例。
- 未经用户明确授权，不替用户发布、发送或写入外部账号。
