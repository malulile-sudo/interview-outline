# interview-outline · Claude Code Skill

> AI 创业者 / 企业 AI 转型决策者访谈大纲生成器

一个面向 Claude Code 的 [Skill](https://docs.claude.com/en/docs/claude-code/skills)。当你准备一期视频号 / 抖音 / 播客 / 行业媒体的 AI 创业者专访时，它会：

1. 自动检索受访者公开输出、行业竞品、市场画像
2. 按 **九大模块** 生成第一轮问题（开场、业务、行业、组织、个人、建议、共情、四个核心信息、大佬观点对照）
3. 在每一问后叠加**追问层**，体现"我懂这个行业、懂你的用户"的姿态
4. 产出一份带短视频切片计划的完整大纲

灵感来源：扣子（Coze）平台「前采之王」智能体的 Claude Code 端可移植版本。

---

## 安装

```bash
git clone https://github.com/malulile-sudo/interview-outline ~/.claude/skills/interview-outline
```

重启 Claude Code，让它扫描新 skill。

## 使用

在 Claude Code 对话里直接说：

> 帮我准备一份采访 XXX 的大纲，他公司是 xxx，公众号 xxx，下周二录

Skill 会自动触发。或者手动调起：

> /interview-outline 受访者：XXX | 公司：YYY | 链接：zzz

## 必备输入

- 受访者姓名 / 公司 / 职位
- 受访者所在赛道
- 至少 1 条受访者过去输出的链接
- 录制时间 / 期望时长（用于切片节奏）

可选：你自己过往访谈实录所在的知识库 / 文档（用于风格模仿）

## 输出格式

```
【人物基础信息】
- 一句话人设
- 最大冲突点
- 最反差点

【九大模块问题清单】
1-9 模块，每问后带「追问」层

【传播切片计划】
- 主视频标题
- 短视频 1（冲突）/ 2（金句）/ 3（方法）
- 互动话题
```

## 个性化建议

本 skill 是通用脚手架。强烈建议你 fork 一份做以下定制：

1. **接入你自己的访谈实录语料**：在 SKILL.md `Step 1.1` 加上你的 Get 笔记 / 飞书 / Notion 知识库 ID
2. **替换风格示例**：把 `风格与限制` 中的 4 条问句风格换成你的真实问法
3. **改受众假设**：把"创业者 / 企业决策者圈层"改成你频道的目标受众

定制完，下次跑大纲的语气就是你自己的。

## 工具映射

`SKILL.md` 内置了一份对照表：扣子（Coze）/ 字节豆包 / 智谱清言等平台上常见的"公众号搜索"、"链接读取"插件，如何用 Claude Code 自带的 WebSearch + WebFetch 兜住。

唯一拿不到的是**文章互动数据**（阅读 / 转发 / 点赞）——建议备采时手动贴关键数字，或接第三方榜单 API。
